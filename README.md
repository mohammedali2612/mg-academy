# MG Academy — Every Child is an Artist 🎨✨

Official modern website for **MG Academy**, an elite children's creative arts & cognitive development center.

## 🌟 Key Features
- **Modern Responsive Design:** Crafted with high-contrast, child-friendly oceanic aesthetic (`#1B365D`, `#005A9C`, `#60C1E5`, `#A0E0EF`).
- **Interactive Peek-a-boo Button:** Custom 3D interactive "Admission Open" button with animated real-time pupil tracking.
- **WebGL2 Fluid GooeyNav:** Liquid metaball category tab navigation on desktop with graceful touch-scrollable mobile fallback.
- **Hero Photo Carousel:** Smooth 3-second automatic crossfade slideshow showcasing academy activities.
- **Programs Covered:** Drawing & Painting, Handwriting Improvement, Speed & Mental Abacus, Classical Bharatanatyam, and Western Dance.
- **Interactive Modals:** Admission enquiry modal, quick demo scheduler, and confetti celebration.

## 🚀 Deploy to Render
This is a zero-build static web application ready for instant deployment on [Render](https://render.com/):

1. Link your GitHub repository `mohammedali2612/mg-academy` on Render.
2. Select **Static Site**.
3. Settings:
   - **Build Command:** *(leave empty)*
   - **Publish Directory:** `.` *(or `./`)*
4. Click **Create Static Site**.
